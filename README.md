# PaperSnap

Android app that turns photos of paper into multi-page PDFs.

- Uses the phone's own camera (full-resolution photos)
- Finds the page edges with OpenCV and straightens it; corners can be adjusted by hand
- Multi-page documents: add, reorder, delete pages
- Import existing images from the gallery
- Optional editor (filters, brightness, contrast, rotate) - enable it in Settings
- PDFs embed the scan's JPEG directly, so no quality is lost
- Works fully offline
